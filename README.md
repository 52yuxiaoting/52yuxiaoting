# 52yuxiaoting

这是 [52yuxiaoting](https://github.com/52yuxiaoting) 的 GitHub 个人主页（Profile）仓库。

## 项目用途

GitHub 会把本仓库根目录下的 `README.md` 显示在账号的[个人主页](https://github.com/52yuxiaoting)上。因此，这个仓库不是一个可运行的程序，也没有构建、安装或启动步骤，它的用途是维护个人主页上展示的内容：

- 用中文介绍这个账号，说明它关注的领域和正在做的事情；
- 汇总并展示后续发布的项目、作品和学习记录；
- 提供一个了解这个账号的统一入口。

## 目前的内容

目前仓库中只有这份 README。后续会随着项目和内容的增加持续补充，计划包括：

- 个人简介；
- 项目与作品列表；
- 其他希望公开的信息。

## 如何更新主页

1. 编辑仓库根目录下的 `README.md`；
2. 把修改提交到 `main` 分支；
3. 打开 <https://github.com/52yuxiaoting> 即可看到更新后的主页内容。

## 说明

本仓库是一个 GitHub Profile 仓库，只包含 Markdown 文档，没有源代码和第三方依赖。
